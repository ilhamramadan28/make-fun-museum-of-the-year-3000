One line: the museum label a museum in the year 3000 puts beside an ordinary
object from today.

> Power Bank, c. 2023. A brick humans carried in every pocket to feed their smaller bricks. It always died first.

`main.py` writes the label to `/output/entry.txt` (UTF-8, 111 chars, one line).
